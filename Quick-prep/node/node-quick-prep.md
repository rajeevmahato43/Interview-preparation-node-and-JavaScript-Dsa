# Node.js Backend Interview Quick Prep: 7 Days

**Audience:** Experienced Node.js backend developers preparing for interviews. Focus is advanced interview readiness; the [42-day course](../../Node/node-roadmap.md) has the deeper runtime and production material.

| Day | Interview focus | Lecture |
| --- | --- | --- |
| 1 | Runtime, modules, process, files, buffers | [Runtime and core APIs](day-01-runtime-and-event-loop.md) |
| 2 | Events, streams, HTTP, networking, workers, diagnostics | [I/O and networking](day-02-http-and-express.md) |
| 3 | Express APIs, validation, errors, auth, security | [Express and API security](day-03-api-design-and-security.md) |
| 4 | MongoDB driver, modeling, indexes, transactions | [MongoDB](day-04-mongodb-essentials.md) |
| 5 | `pg`, SQL, constraints, indexes, MVCC, transactions | [PostgreSQL](day-05-postgresql-essentials.md) |
| 6 | Architecture, retries, cache, queues, observability | [Reliability and operations](day-06-reliability-and-operations.md) |
| 7 | Testing, performance, integration, capstone | [Backend synthesis](day-07-backend-interview-synthesis.md) |

MongoDB and PostgreSQL focus on commonly tested application-level decisions. Each lesson is topic-wise, briefly defined, linked to the full Node lecture, and ends with numbered `Tricky points`.
