# JavaScript Interview Quick Prep: 7 Days

**Audience:** Candidates with JavaScript experience preparing for mid-to-senior interviews. This is a high-yield refresh, not a substitute for the [28-day course](../../Javascript/javascript-roadmap.md).

| Day | Interview focus | Lecture |
| --- | --- | --- |
| 1 | Syntax, declarations, values, coercion | [JavaScript foundations](day-01-values-and-coercion.md) |
| 2 | Control flow, functions, scope, closures, `this`, errors | [Control flow and functions](day-02-scope-closures-and-this.md) |
| 3 | Objects, prototypes, classes, arrays, collections, JSON | [Objects and collections](day-03-objects-and-prototypes.md) |
| 4 | Destructuring, iteration, generators, regex, proxies | [Modern syntax and protocols](day-04-collections-and-arrays.md) |
| 5 | Modules, promises, async/await, scheduling | [Modules and asynchronous JavaScript](day-05-promises-and-async.md) |
| 6 | Memory, performance, testing, debugging | [Runtime behavior and verification](day-06-event-loop-and-scheduling.md) |
| 7 | Security, service boundaries, concurrency | [Security and integration](day-07-senior-interview-synthesis.md) |

Each lesson is organized by topic, uses short numbered explanations, links to the matching full-course topics, and ends with grouped `Tricky points`.
