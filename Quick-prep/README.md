# Quick Interview Prep

Six independent, seven-day interview sprints for candidates who need a focused refresh rather than another full course. Each day targets high-yield concepts, common traps, and short interview practice. Start with the track closest to your target role; use deeper-course links only when a topic needs more explanation.

These sprints assume prior exposure and are not a promise of expertise in seven days. JavaScript, Node.js, DSA, and system design focus on advanced interview readiness. React and Angular focus on practical fluency and interview terminology for backend developers, not framework mastery.

| Track | Seven-day focus | Target level | Roadmap |
| --- | --- | --- | --- |
| JavaScript | Semantics, scope, objects, async, runtime traps | Advanced interview refresh | [JavaScript quick prep](javascript/javascript-quick-prep.md) |
| Node.js | Runtime, APIs, reliability, MongoDB, PostgreSQL | Advanced backend interview refresh | [Node.js quick prep](node/node-quick-prep.md) |
| DSA | Core patterns, correctness, complexity, timed practice | Advanced interview refresh | [DSA quick prep](dsa/dsa-quick-prep.md) |
| System Design | Interview method, data, scale, reliability, case practice | Advanced interview refresh | [System design quick prep](system-design/system-design-quick-prep.md) |
| React | Components, state, hooks, data flow, everyday debugging | Backend developer working fluency | [React quick prep](react/react-quick-prep.md) |
| Angular | Components, templates, DI, RxJS, routing, forms | Backend developer working fluency | [Angular quick prep](angular/angular-quick-prep.md) |

**Lesson format:** Concise numbered topics with short definitions, tiny examples where useful, links to full-course topics (or official React/Angular docs), and one final hierarchical `Tricky points` section. See [quick-prep rules](../DOCS/quick-prep-rules.md).
