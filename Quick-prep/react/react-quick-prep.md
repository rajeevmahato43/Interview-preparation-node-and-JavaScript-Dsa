# React Interview Quick Prep: 7 Days

**Audience:** Backend developers who need to discuss React terminology and contribute to ordinary React application work. This track targets working fluency, not expert-level rendering or framework specialization. For current behavior, consult the [React documentation](https://react.dev/learn).

| Day | Interview focus | Lecture |
| --- | --- | --- |
| 1 | Components, JSX, props, lists, conditional UI | [Components and JSX](day-01-components-and-data-flow.md) |
| 2 | State snapshots, updates, rendering, ownership | [State and rendering](day-02-state-and-rendering.md) |
| 3 | Hooks, refs, Effects, cleanup, custom hooks | [Hooks and Effects](day-03-hooks-and-effects.md) |
| 4 | Events, controlled/uncontrolled inputs, validation | [Events and forms](day-04-events-and-forms.md) |
| 5 | Async data states, races, navigation, API boundary | [Data and navigation](day-05-data-and-navigation.md) |
| 6 | Context, reducers, render causes, performance, errors | [State structure and debugging](day-06-structure-and-debugging.md) |
| 7 | Feature flow, accessibility, backend integration | [Feature review](day-07-interview-practice.md) |

Lessons use brief numbered topic definitions and finish with grouped `Tricky points`. **Out of scope:** advanced concurrent-rendering internals, custom renderer work, and specialist performance tuning.
